Service status

This is where live service status will appear once the hosted pilot is running.

Live status is not connected yet

There is no hosted service to monitor yet, so this page has nothing to report. It does not mean everything is working, and it does not mean something is broken.

What this page will show

  • Whether tables can start and resume.
  • Problems with an AI service that pause narration, voices or pictures.
  • Problems with payments or credit.
  • Planned maintenance.

For each incident it will give the start time, what is affected, and whether anyone was charged during it. We do not publish an uptime guarantee for the pilot.

In the meantime, the help page explains what to do if play stops.
