Estado del servicio

Aquí aparecerá el estado del servicio cuando comience el programa piloto alojado.

El estado en tiempo real aún no está conectado

Todavía no hay un servicio alojado que supervisar, así que esta página no tiene novedades. Eso no significa que todo funcione ni que haya algún problema.

Qué mostrará esta página

  • Si las mesas pueden iniciar y reanudar partidas.
  • Problemas con un servicio de IA que pausen la narración, las voces o las imágenes.
  • Problemas con los pagos o el crédito.
  • Mantenimiento programado.

Cada incidente incluirá la hora de inicio, los servicios afectados y si se cobró a alguien durante ese período. No ofrecemos una garantía de disponibilidad para el programa piloto.

Mientras tanto, la página de ayuda explica qué hacer si se interrumpe la partida.
