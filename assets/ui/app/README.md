# DungeonFlux application icon

Generated with OpenAI ImageGen on 2026-10-23 for the DungeonFlux desktop shortcut
and Windows executable, at the user's request. The original RGBA output is
`dungeonflux.png` (1254 × 1254 pixels). It has not been aesthetically edited.

`dungeonflux.ico` packages that image, preserving alpha, at 16, 24, 32, 48, 64,
128 and 256 pixels using Pillow's ICO encoder. The PNG is the durable source;
no generated-image cache path is required to build or install the application.

The Windows build resource is `crates/df-tools/windows/dungeonflux.rc`.
